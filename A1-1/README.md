# 이커머스 멀티모달 데이터 분석과 RFM 고객 세분화

온라인 쇼핑몰의 거래 데이터(수치, 텍스트, 날짜)와 상품 이미지 배열을 NumPy와 Pandas로 전처리하고, 탐색적 데이터 분석(EDA)과 RFM 분석으로 고객을 5개 그룹으로 나눠 비즈니스 전략을 제안한 프로젝트입니다.

## 1. 프로젝트 개요

- **분석 대상**: 영국 온라인 선물용품 업체의 2년치 거래 1,067,371건
- **핵심 내용**
  - 이미지 6만 장의 평균·표준편차를 **반복문 없이** NumPy 벡터 연산으로 수치 피처로 변환
  - 그룹별 결측치 대치, IQR 이상치 탐지와 범위 제한(클리핑)
  - 통계 분석, 시각화 6종, 고객 5,878명의 RFM 세분화
- **구현 방식**: 분석 로직을 `DataAnalyzer` 클래스(`src/pipeline.py`)로 구조화하고, 노트북에서 불러와 사용
- **사용 라이브러리**: NumPy, Pandas, Matplotlib, Seaborn (이미지 처리 전용 라이브러리와 머신러닝 라이브러리는 사용하지 않음)

## 2. 데이터 설명

| 구분 | 이름 | 규모 | 용도 |
|---|---|---|---|
| 거래 데이터 | Online Retail II | 1,067,371행 × 8열 | 전처리, 통계, 시각화, RFM |
| 이미지 데이터 | Fashion-MNIST (학습용 60,000장) | 28×28 흑백, 값 범위 0에서 255 | 이미지 수치화 연습 |

### 거래 데이터 열

| 열 | 설명 | 유형 |
|---|---|---|
| `invoice` | 주문번호 (`C`로 시작하면 취소 주문) | 범주 |
| `stock_code` | 상품 코드 | 범주 |
| `description` | 상품명 | 텍스트 |
| `quantity` | 주문 수량 | 수치 |
| `order_date` | 주문 일시 (2009-12-01 부터 2011-12-09 까지) | 날짜 |
| `price` | 단가 (영국 파운드) | 수치 |
| `customer_id` | 고객 번호 (익명 숫자) | 범주 |
| `country` | 고객 국가 | 범주 |

분석 중 새로 만든 열: `img_mean`, `img_std`(이미지 평균·표준편차), `name_word_count`, `name_length`(상품명 단어 수·글자 수), `amount`(수량 × 단가), `*_clipped`(범위 제한 후 값)

데이터 유형은 수치, 범주, 텍스트, 날짜, 이미지 배열로 5가지입니다. 업체는 주로 선물용품을 팔고 도매 고객이 많다고 설명되어 있습니다.

### 한계: 이미지와 상품의 연결은 시뮬레이션입니다

거래 데이터에는 이미지가 없어서 출처가 다른 Fashion-MNIST를 붙였습니다. **상품과 이미지의 연결은 난수(시드 42)로 정한 학습용 시뮬레이션이며 실제 상품 사진이 아닙니다.** 이미지 피처는 NumPy 벡터 연산으로 이미지를 수치화하는 연습용이고, 비즈니스 인사이트에는 사용하지 않았습니다. 상관계수에서도 이미지 평균과 구매 금액의 상관은 -0.01로 거의 없었습니다.

## 3. 분석 결과 요약

### 3-1. 데이터 정제

| 단계 | 내용 | 결과 |
|---|---|---|
| 상품명 결측 대치 | 같은 상품 코드의 최빈값으로 채움 | 4,382개 중 4,019개(91.7%) 채움, 363개 남음 |
| 중복 제거 | 모든 열이 같은 행 | 34,335행 |
| 판매가 아닌 행 제거 | 취소 주문, 수량·가격이 0 이하 | 25,123행 |
| 정제 결과 | | 1,067,371행에서 1,007,913행으로 (5.6% 제거) |

고객 번호가 비어 있는 행은 22.7%입니다. 평균으로 채울 수 없는 식별 정보라서 대치하지 않고 RFM 계산에서만 제외했습니다.

### 3-2. 이상치 (IQR 1.5배 기준)

| 변수 | 이상치 수 | 비율 | 위 울타리 |
|---|---|---|---|
| 수량 | 53,061 | 5.3% | 28.5 |
| 가격 | 78,999 | 7.8% | 8.45 |
| 금액 | 84,954 | 8.4% | 38.06 |

이상치가 5%를 넘고 도매 고객의 대량 주문일 수 있어 삭제하지 않고 울타리 값으로 **범위 제한**했습니다. 수량의 평균은 11.12에서 7.07로 줄었지만 중앙값(4)은 그대로였습니다.

### 3-3. RFM 세그먼트

R(마지막 구매 후 일수, 기준일 2011-12-09), F(서로 다른 주문번호 수), M(주문 금액 합계)에 각각 1점에서 5점을 매기고 아래 규칙으로 나눴습니다. 조건은 위에서부터 차례로 확인합니다.

| 세그먼트 | 조건 | 고객 수 | 비율 | 평균 구매 횟수 | 구매 금액 중앙값 | 금액 비중 |
|---|---|---|---|---|---|---|
| VIP | R≥4, F≥4, M≥4 | 1,274 | 21.7% | 17.3회 | 4,002 | 68.0% |
| Loyal | F≥4, R≥3 | 604 | 10.3% | 8.3회 | 1,895 | 10.1% |
| New | R≥4, F≤2 | 506 | 8.6% | 1.5회 | 383 | 2.4% |
| Regular | 나머지 | 1,147 | 19.5% | 2.7회 | 715 | 6.5% |
| Churned | R≤2 | 2,347 | 39.9% | 2.5회 | 406 | 12.9% |

금액 단위는 영국 파운드이고, 고객 번호가 있는 거래의 구매 금액 합계는 약 1,737만입니다. 평균 구매 금액은 모든 세그먼트에서 중앙값보다 커서(예: VIP 9,276 대 4,002) 소수의 매우 큰 고객이 평균을 끌어올립니다.

## 4. 비즈니스 인사이트

아래 **기대 효과**는 복귀율 10% 같은 단순 가정으로 어림 계산한 값이며 실제 효과를 보장하지 않습니다. 비율은 고객 번호가 있는 거래의 구매 금액 합계(약 1,737만)를 기준으로 했습니다.

### [인사이트 1] 매출은 VIP에 집중되어 있어 VIP 유지가 최우선이다

- **(근거)** VIP 1,274명(고객의 21.7%)이 전체 구매 금액의 68.0%를 차지한다. 구매 금액의 중앙값도 VIP는 4,002로 Churned(406)와 New(383)의 약 10배다. (노트북 8번 표)
- **(실행)** 대상은 VIP다. 성수기가 시작되는 9월 전에 전용 사전 안내와 우선 재고 확보, 담당자 연락 같은 멤버십 혜택을 강화한다. 기대 효과는 VIP의 5%가 이탈하는 것을 막으면(VIP 금액이 고르다고 단순 가정) 전체 구매 금액의 약 3.4%(68.0% × 5%)를 지킬 수 있다는 것이다.
- **(검증)** VIP의 평균 구매 금액(9,276)이 중앙값(4,002)의 2.3배라서 소수의 초대형 고객이 VIP 금액을 좌우할 수 있으므로, VIP 안에서 상위 고객이 차지하는 비중과 취소 주문을 보정한 뒤에도 68%가 유지되는지 확인해야 한다.

### [인사이트 2] 이탈 고객의 복귀는 성수기 직전에 노린다

- **(근거)** Churned는 2,347명으로 고객의 39.9%로 가장 큰 그룹이지만 구매 금액 비중은 12.9%에 그친다. 마지막 구매 후 평균 426.6일이 지났고 평균 구매 횟수는 2.5회다. 월 매출은 두 해 모두 9월부터 오르기 시작해 11월에 최고점(2011년 11월 1,503,867)이다.
- **(실행)** 대상은 Churned다. 성수기 직전인 9월 초에 복귀 쿠폰과 인기 상품 안내 메일을 보낸다. 기대 효과는 Churned의 10%(약 235명)가 돌아와 이 그룹의 구매 금액 중앙값(406)에서 평균(956) 사이만큼 구매하면 약 95,000에서 224,000이고, 전체 구매 금액의 약 0.5%에서 1.3%다. (복귀율 10%는 가정)
- **(검증)** 연말에만 구매하는 계절성 고객이 Churned에 섞여 있을 수 있어, 전년도 같은 시기의 구매 이력(연도별 재구매 패턴)이 있어야 이탈과 계절성을 구분할 수 있다.

### [인사이트 3] 매출이 연말 성수기에 몰리므로 9월 전에 재고를 준비한다

- **(근거)** 월 매출 상위 3개 월이 모두 10월과 11월이다. 2011년 11월 1,503,867, 2010년 11월 1,464,293, 2010년 10월 1,161,902 순이다. 두 해 모두 9월부터 오르기 시작해 11월이 지나면 크게 줄어든다. (노트북 7번 월별 매출 그래프)
- **(실행)** 대상은 재고와 운영이며, 사전 안내의 우선 대상은 구매 빈도가 높은 VIP와 Loyal이다. 8월 말까지 주문이 많은 상품(수량 6, 12, 24개 같은 묶음 단위 포함)의 재고를 확보하고 9월 초에 사전 안내한다. 기대 효과는 성수기 품절로 인한 매출 손실을 줄이는 것이다.
- **(검증)** 두 해 치 데이터뿐이라 같은 패턴이 매년 반복되는지 알 수 없고, 품절·재고 기록이 있어야 손실 규모를 계산할 수 있다.

### [인사이트 4] New 고객의 두 번째 구매를 유도한다

- **(근거)** New는 506명(8.6%)으로 최근에 구매했지만 평균 구매 횟수가 1.5회, 구매 금액 중앙값이 383이다. Loyal은 평균 8.3회, 중앙값 1,895다.
- **(실행)** 대상은 New다. 첫 구매 후 재구매 쿠폰과 수량 분포에서 많이 나온 묶음 단위(6, 12, 24개) 상품 추천을 보낸다. 기대 효과는 New의 10%(약 51명)가 Loyal 중앙값 수준(1,895)으로 구매하면 증가분이 약 76,500이고 전체 구매 금액의 약 0.4%다. (10%는 가정)
- **(검증)** 쿠폰을 받은 고객과 받지 않은 고객의 재구매율을 비교하는 실험 데이터가 있어야 효과를 확인할 수 있다.

## 5. 한계

- 이미지와 상품의 연결은 난수 시뮬레이션이다. 이미지 피처는 인사이트에 사용하지 않았다.
- 취소 주문(`C`)은 제외했지만 취소된 **원래 주문은 남아 있다.** 예를 들어 80,995개 주문은 12분 뒤 같은 고객이 전량 취소했는데, 원래 주문이 매출에 남아 해당 고객의 구매 금액이 약 168,470으로 부풀려졌다. 구매 금액이 일부 과대 계상될 수 있다.
- 모든 열이 같은 행을 전부 제거했으므로, 같은 주문에서 같은 상품을 두 번 입력한 정상 행도 함께 제거됐을 수 있다. 중복의 약 67%(23,023행)가 2010년 12월에 몰려 있어 엑셀 시트 2개의 기간이 겹친 영향으로 보인다(추정).
- 마지막 달(2011-12)은 9일치라 월별 매출 추이에서 제외했다.
- 세그먼트 기준(점수 4 이상 등)은 분석자가 정한 규칙이라 다른 기준을 쓰면 고객 수가 달라진다.
- 2년치 데이터라 계절성과 추세를 구분하기 어렵다.

## 6. 폴더 구조

```
A1-1/
├── README.md
├── requirements.txt
├── .gitignore

│   └── pipeline.py        # DataAnalyzer 클래스
└── notebooks/
    └── analysis_report.ipynb
```

`DataAnalyzer`의 주요 메서드는 다음과 같습니다.

| 메서드 | 역할 |
|---|---|
| `load_data()` | 거래 데이터와 이미지 불러오기 |
| `handle_missing_values(target_col, group_col, strategy)` | 그룹별 결측치 대치 (최빈값, 중앙값, 평균) |
| `add_image_features()` | 이미지 평균·표준편차 (벡터 연산) |
| `add_text_features()` | 상품명 단어 수, 글자 수 |
| `clean_data()` | 중복 제거, 판매 행 선별, 금액 계산 |
| `detect_outliers(column, threshold)` | IQR 이상치 탐지 |
| `clip_outliers(column, threshold)` | 이상치 범위 제한 |
| `calculate_rfm(customer_col, date_col, amount_col)` | RFM 점수와 세그먼트 |

## 7. 실행 방법

Python 3.11 이상을 권장합니다.

### 7-1. 환경 만들기

```bash
git clone <저장소 주소>
cd A1-1
python3 -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
python -m pip install -r requirements.txt
```

### 7-2. 데이터 내려받기

원본 데이터는 용량과 재배포 문제로 저장소에 포함하지 않았습니다. 아래 두 파일을 `data/raw/` 폴더에 넣어 주세요.

1. **거래 데이터**: https://archive.ics.uci.edu/dataset/502/online+retail+ii 에서 내려받은 압축 파일(직접 링크: https://archive.ics.uci.edu/static/public/502/online+retail+ii.zip)을 풀어 `online_retail_II.xlsx`를 넣습니다.
2. **이미지 데이터**:
   ```bash
   curl -L -o data/raw/train-images-idx3-ubyte.gz https://raw.githubusercontent.com/zalandoresearch/fashion-mnist/master/data/fashion/train-images-idx3-ubyte.gz
   ```

### 7-3. 노트북 실행

```bash
jupyter notebook
```

`notebooks/analysis_report.ipynb`를 열고 **Kernel → Restart Kernel and Run All Cells**를 실행합니다. 처음 실행할 때는 엑셀을 읽는 데 몇 분이 걸리고, `data/raw/online_retail_ii.csv`로 저장해 두어 다음부터는 빠르게 읽습니다.
